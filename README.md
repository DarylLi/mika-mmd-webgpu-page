MMD animation rendered by three.js WebGPU.

## Features

- WebGPU rendering engine
- Support for MMD models (.pmx) and animations (.vmd)
- Animation playback controls

## Quick Start

### Install dependencies

```bash
npm install
```

### Development mode

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview build result

```bash
npm run preview
```
